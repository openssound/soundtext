# Istruzioni per Claude

- All'inizio di ogni sessione, esegui `git pull` prima di modificare codice.
- A fine sessione (o quando richiesto), esegui `git add .`, `git commit`
  con un messaggio descrittivo, e `git push`.
- Non versionare mai file .sf2/.sf3 o altri file audio di grosse
  dimensioni: vanno esclusi via .gitignore.
