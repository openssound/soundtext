# Licenze degli strumenti SFZ di `scarica_strumenti.sh`

Licenze lette dai file scaricati (`~/Strumenti/sfz/`) e dal campo licenza dei
repository su GitHub. Verifica sempre il file di licenza dentro ogni cartella
prima di un uso commerciale o di una ridistribuzione.

L'obbligo di attribuzione riguarda soprattutto chi ridistribuisce i campioni.
Pubblicando un brano suonato con uno strumento CC-BY, la prassi e' citare
comunque l'autore nei crediti.
